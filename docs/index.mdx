Sonicverse is a self-hosted Docker stack for live radio streaming. Ingest from any studio encoder, deliver MP3, AAC, Ogg, and HLS to listeners, and run an optional real-time operator dashboard. The runtime now ships as a single consolidated Docker image managed by one supervised entrypoint.

<Note>
  Sonicverse is in early development. APIs, configuration, and behaviour may change without notice. Don't run this in production without thorough evaluation.
</Note>

## What you get

- **Studio ingest** on two harbor ports (`8010` primary, `8011` fallback) with automatic silence detection and failover to a local emergency MP3.
- **Listener distribution** via Icecast2 in MP3 (128/192/320 kbps), AAC (128/192 kbps), and Ogg Vorbis (128 kbps).
- **HLS adaptive bitrate** at `/hls/live.m3u8` for mobile and browser players.
- **Automatic TLS** via Let's Encrypt with hot reload — no downtime on renewal.
- **Optional operator dashboard** with live listener counts, container health, and emergency audio management, secured by Appwrite team-based auth.
