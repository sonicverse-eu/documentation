## July 14, 2026

### Audio streaming stack

<Update label="New features">
  **Stack config control plane.** The status API now exposes `/api/stack/*` endpoints for managing ingests, Icecast outputs, HLS variants, and processing settings as a validated JSON document. Operators can add or remove mounts, tweak bitrates, and reload Liquidsoap and Icecast without editing config files by hand. See [Stack config control plane](/operators/stack-config) for the full endpoint reference and examples.
</Update>

## June 12, 2026

### Audio streaming stack

<Update label="New features">
  **Unified runtime image.** The streaming services now ship as a single consolidated Docker image managed by one container entrypoint. Fewer moving parts to deploy, simpler upgrades, and a smaller surface to monitor when running a station. See [sonicverse.tech](https://sonicverse.tech) for project overview.
</Update>

<Update label="Updates">
  **Analytics integration removed.** The optional PostHog analytics layer has been pulled out of the stack. Operators no longer need to configure analytics environment variables, and listener traffic is not tracked by default.
</Update>

<Update label="Bug fixes">
  - **Status API now starts reliably** inside the unified container, so the operator dashboard and service health checks come up consistently on first boot.
</Update>

### Website

<Update label="New features">
  **Rebrand around the open broadcast stack.** The Sonicverse marketing site has been rebuilt around the open broadcast stack story, with refreshed messaging, a new [open source](https://sonicverse.tech/open-source) section, and an updated [roadmap](https://sonicverse.tech/roadmap).
</Update>
